# Contract Pricing Program

**CIS 199 – Software Development I | C# Windows Forms**

## Project Overview
Developed a Windows Forms application that calculates consultant contract pricing based on the selected consultant, business, and contract length using arrays and conditional logic.

## Features
- Selects consultants and businesses from dropdown menus.
- Uses arrays to retrieve pricing and discount information.
- Applies savings based on contract length.
- Validates required selections and contract length before calculating.
